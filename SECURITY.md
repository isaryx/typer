# Security Policy

## Supported Versions

Security fixes are handled on a best-effort basis, with priority for the latest released version.

## Reporting a Vulnerability

If possible, avoid sharing vulnerability details in public issues.

Use one of these paths:

- Preferred: GitHub private vulnerability reporting (Security Advisories) for this repository.
- Fallback: open a public issue with minimal details and request a private follow-up channel.

## Response Targets

- Initial acknowledgement: usually within 3-5 business days.
- Triage decision: typically within 1-3 weeks.
- Status updates: when there is meaningful progress.

## Disclosure

After a fix is available, we will coordinate responsible disclosure and publish a release note describing impact, affected versions, and remediation steps.
